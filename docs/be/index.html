Minecraft 基岩版入门

本页面向使用 Minecraft: Bedrock Edition（基岩版） 的玩家。开始前确认你设备上安装的版别：Java 版与基岩版是不同游戏发行版，联机、存档和内容包并非都能互换。

购买与启动

  • 从 Minecraft 官方网站或设备对应的官方应用商店查看购买/安装选项，先确认设备系统、地区与游戏版别。PC 上的 Java & Bedrock Bundle 不代表所有主机、移动平台的商店和权益都相同。
  • 启动游戏时使用自己的 Microsoft 账号登录；不要向任何人分享密码、验证码或恢复代码。若无法登录，请使用 官方账户登录帮助。
  • 确保游戏与好友使用兼容的游戏版本；通过各平台官方更新渠道更新，不要安装来历不明的改版包。

创建世界并开始游玩

  1. 从主菜单进入“游戏”，新建世界或选择本地已有世界。
  2. 新建时选择生存/创造等模式与难度；初次体验可保持默认设置。涉及多人游戏时再检查世界设置中的多人选项与加入权限。
  3. 开始重要建筑或长期生存前，确认世界可在当前设备上保存，并了解本平台的备份/导出路径。设备重置、卸载游戏或更换账号前，先完成可靠备份。

与好友联机

  • 基岩版好友一般通过 Microsoft/Xbox gamertag 与平台好友或邀请流程加入；具体操作和跨平台可用性取决于设备、隐私/家长控制设置及账号状态。
  • 在可用平台上，基岩版玩家可彼此跨设备游玩，但双方需要相容的 Bedrock 版本并满足各自平台的联网/多人条件。
  • Java 版与基岩版不能直接互相加入对方的原生世界。社区项目 Geyser 可搭建协议桥接服务器，但需要服务器端配置、兼容版本和 Bedrock UDP 网络访问；详见本站的 Geyser 跨平台联机指南。
  • 若希望世界在房主离线时仍可加入，可了解官方 Minecraft Realms；订阅、平台支持和转移步骤以官方说明为准。

保护与转移世界

  • 不要把唯一一份世界存档放在即将卸载或重置的设备上。关闭游戏后，按设备官方步骤复制/导出世界并在另一位置确认备份可读取。
  • 基岩版世界格式与 Java 版不同，不能通过把文件夹复制到 Java 的 saves 目录完成转换。跨版转换通常依赖第三方工具，可能遗失区块、实体、物品或机制；先备份，并只在副本上尝试。
  • 若通过 Realms 转移世界到另一设备，请使用与目标版别和平台匹配的官方传输流程，参考 官方 Bedrock 世界转移说明。
  • 购买的商店内容、账号、世界存档与服务器订阅是不同的数据/权益；迁移其中一项不代表其他项目也会随之转移。
