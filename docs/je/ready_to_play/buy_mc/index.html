Minecraft Java 版正版购买与登录

账号、商店界面、付款方式和地区可用性会变化。请以 Microsoft/Xbox 商店与 Minecraft 官方帮助中心当前显示为准。不要向他人购买、出售或借用账号，也不要把密码、验证码或恢复代码交给任何人。

一、购买前确认

Minecraft 官方帮助中心说明：个人电脑版本的 Minecraft: Java & Bedrock Edition for PC 套装提供 PC 上的 Java Edition 与 Bedrock Edition 权益；Windows 用户可玩两个版本，macOS/Linux 支持 Java Edition。不同平台单独购买的版本、商品和地区供应范围并不相同。

  1. 打开 Minecraft 官方 PC 版购买指引 中列出的 Microsoft/Xbox 商店或 Minecraft.net 购买入口。
  2. 先登录或创建你准备长期使用的 Microsoft 账户，再检查商品名称、适用平台、地区、年龄/家庭设置、售价与支付方式。
  3. 只有在官方商店明确显示适用于你的地区且你确认商品与账户无误时再购买。各地区的商店目录和可用付款方式可能不同；本文不保证某个具体商店、银行卡或第三方支付方式在所有地区可用。
  4. 购买成功后保留订单确认信息。游戏许可证关联购买时所用的 Microsoft 账户，通常不能转到另一个账户；如购买错账户，联系官方支持，不要通过账号交易处理。

二、安装启动器并核对权益

  1. 从 Minecraft 官方下载页或 Microsoft Store 安装 Minecraft Launcher。
  2. 启动器左上角选择 Microsoft 登录，登录购买游戏时使用的 Microsoft 账户。
  3. 从左侧选择 Minecraft: Java Edition，如果该账户拥有权益，应出现“Play/Install”等按钮；“Buy Now”往往表示当前登录账户未检测到该版本权益。
  4. 先检查是否登录错了账户，再打开 Microsoft Store/Xbox 应用核对账户。官方说明可参考查询自己拥有的 PC 版本。
  5. 选择游戏版本并安装，再按启动器提示启动。是否拥有基岩版、Java 版或两者，以该账户当前的商店/启动器权益显示为准。

三、启动器显示“购买”但你已购买

  • 在启动器右上/左上账户菜单核对电子邮箱/账户名称；家庭共用电脑常因登录到另一位用户账户而显示“Buy Now”。
  • 若有多个账户，按 官方账户切换步骤切换，再退出并重开启动器。
  • 确认商店和 Launcher 登录账户符合预期；浏览器登录正确不等于启动器也已登录正确。
  • 若仍未识别权益，查看微软账户登录排障，必要时联系 Microsoft/Minecraft 官方支持，并提供订单凭据而非密码。

四、账号安全

开启 Microsoft 账户可用的安全验证方式，使用唯一且不重复的密码；不要公开分享登录代码、恢复密钥、Cookie 或启动器令牌。若怀疑账号被盗，使用官方账户恢复渠道。未成年人购买或创建账户时应遵循所在地规则及家长/监护人要求。
