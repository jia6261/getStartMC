# Minecraft 常见术语对照与易错概念

> Minecraft 不同版本、官方中文翻译与中文玩家社区的习惯称呼可能不同。下表优先使用当前游戏/官方帮助页面中的概念；“俗称”用于帮助理解，不代表官方术语。

| 中文建议用语 | 英文 | 常见别称/旧称 | 易错点 |
| --- | --- | --- | --- |
| Minecraft Java 版 | Minecraft: Java Edition | Java 版、JE | 主要在 Windows、macOS、Linux PC 上游玩；不是泛指所有“电脑版”。 |
| Minecraft 基岩版 | Minecraft: Bedrock Edition | Bedrock、BE；旧称 PE 常被泛指手机版 | 除 Windows 外也有移动设备、主机等平台；不同平台的功能、商店和联网规则可能不同。 |
| 世界 / 存档 | world / save | 地图、档 | “地图”常指可下载的关卡；存档文件夹通常还含玩家、维度和世界设置数据。 |
| 启动器 | launcher | 启动端 | 用于登录、安装/选择版本和启动游戏；启动器不是游戏服务端。 |
| 客户端 / 服务端 | client / server | 玩家端 / 服 | 客户端是玩家运行的游戏；服务端负责托管多人世界。两者通常需要兼容的游戏版本。 |
| 资源包 | resource pack | 纹理包、材质包（旧称/俗称） | 资源包可替换纹理，也可能包含声音、模型、字体、语言等；“纹理包”只覆盖其中一部分。 |
| 数据包 | data pack | datapack | Java 版数据驱动内容包；不等同于模组、资源包或 Bedrock Add-On。 |
| 模组 | mod / modification | MOD | Java 社区常指修改/扩展游戏的加载内容；通常须与对应游戏版本和加载器匹配。模组不是官方 Add-On 的同义词。 |
| 插件 | plugin | 服务端插件 | 通常扩展特定服务端软件（如 Paper）；与需要客户端模组加载器的模组不是一回事。 |
| 加载器 | mod loader | 模组加载器 | Forge、NeoForge、Fabric 等各有生态；仅安装加载器不代表模组自动兼容。 |
| 附加包 | add-on | 基岩版 Add-On | 常用于基岩版的资源包/行为包体系；不应写成 Java 模组的直接等价物。 |
| 进度 | advancement | Java 版常被俗称“成就” | Java 版当前使用 advancements；旧 Java Achievement 系统已被进度取代。 |
| 成就 | achievement | Xbox/Bedrock 成就 | 基岩版平台成就和 Java 版进度不是同一个系统。 |
| 红石 | redstone | 红石电路 | Java 和 Bedrock 的红石行为并不总是完全一致，教程要标注对应版本。 |
| 种子 | seed | 世界种子 | 用于生成世界的输入；版本、版别或生成规则改变后，同一数字种子不保证生成完全相同的世界。 |
| Realms | Minecraft Realms | 官方领域/Realm | Mojang 提供的在线托管订阅服务；不是所有版本、平台之间都可自由互通。 |
| 局域网开放 | Open to LAN | LAN 联机 | Java 单人世界临时开放给局域网；这不等于创建 24 小时在线的专用服务器。 |
| UUID | Universally Unique Identifier | 玩家 UUID | 玩家档案标识；身份验证模式变化可能影响服务器识别到的档案。不是玩家名。 |
| 白名单 | whitelist / allowlist | 允许列表 | 服务器控制允许加入的账号；不是防火墙，也不能替代安全更新和账号保护。 |
| 错误日志 / 崩溃报告 | log / crash report | latest.log、crash report | 日志通常记录运行过程；崩溃报告是特定异常时生成的诊断文件，两者不完全相同。 |
| Java 运行环境 | Java Runtime Environment (JRE) | Java、JDK（常被混用） | 游戏需要匹配版本的 Java 运行环境；JDK 是开发工具包，也包含运行组件。并非每个游戏版本都应安装“最新 Java”。 |

## 三个容易混淆的判断

1. **Minecraft 不是单一平台版本**：讨论下载、模组、跨平台联机或迁移存档时，先确认 Java Edition 还是 Bedrock Edition。
2. **内容类型不可互换**：资源包主要控制资源表现；数据包扩展 Java 世界数据；模组依赖加载器；插件依赖服务端；基岩 Add-On 有自己的结构。
3. **社区俗称不一定准确**：“材质包”常被理解为“资源包”，“成就”常被用来泛指 Java 进度。写教程时首次出现可同时注明官方名称与常用别称。
